# pi-precognition v0.3 Release Gates

Status: local release-candidate work only. Do not tag, push, publish, create a GitHub release, or post a public announcement from this loop.

## North Star

Ship a 9.2+ v0.3 local release candidate that preserves public v0.2 safety while making persistent operator-time anticipation visible: Pattern Library, live mutation re-arming, pi-blitz futures, benchmark evidence, extensibility, and a coherent release narrative.

## Ask-Before Operations

Stop and ask the maintainer before:

- `git push`
- `git tag`
- `npm publish`
- creating GitHub releases
- posting public announcements
- installing new dependencies
- deleting unrelated files
- destructive cleanup outside generated `.pi-precognition`, `validation`, and docs/demo artifacts
- modifying global Pi or `/until-done` config
- changing public safety defaults

## Required Bootstrap Gates

1. Canonical gates/rules/failure conditions: this file.

4. Changed-file or affected-target execution: `mise run precog:affected` with documented safe fallback.
5. Deterministic caching or no-cache fallback: documented in `docs/v0.3-automation-parity.md`.
6. Safe parallel execution policy: documented in `docs/v0.3-automation-parity.md`.
7. Matching minimal GitHub Agentic Workflow: `.github/workflows/v0.3-agentic-validation.yml`.
8. Local ↔ GitHub parity notes: `docs/v0.3-automation-parity.md`.

Production tests or production code changes may not begin until these bootstrap gates exist and the local bootstrap validation passes.

## Final Verify Command

```bash
mise exec -- bash -lc 'cd <repo> && npm test && npm run typecheck && node ./src/cli.ts doctor && node ./src/cli.ts patterns && node ./src/cli.ts watch --once && PI_PRECOG_COMMAND_FUTURES=1 PI_PRECOG_TOOL_CACHE=1 node ./src/cli.ts bench --paired --workload all --iterations 5 --out validation && npm pack --dry-run --json'
```

Completion requires quoting the real stdout/stderr from this command and separate evidence for n >= 15 paired expensive-future runs across at least 3 real projects.

## v0.2 Foundation Must Remain Intact

The release fails if any existing public v0.2 safety behavior weakens:

- safe-by-default silent futures
- no answer prediction
- no speculative mutation
- command futures remain allowlisted and opt-in
- command cache validates causal fingerprints before serving
- cache-invariant micro-delay remains intact for extension mode
- repo containment and secret-path denial remain intact
- all existing safety tests pass

## v0.3 Ship Blockers

- Pattern Library persists ranked useful patterns with path patterns, armed futures, hit/miss counts, saved time, and rejection reasons.
- `patterns` shows persistent value, not only current-session noise.
- `patterns --live` or `watch` visibly reacts to mutations and updates armed futures/confidence.
- Mutation stream re-evaluates and re-arms expensive futures after file changes.
- Causal drift rejection reasons are human-readable.
- pi-blitz future classes are first-class and surfaced in learned patterns.
- Future Compose API ships with pi-blitz plus one non-trivial external-style class.
- Benchmark report includes n >= 15 paired expensive-future runs across >= 3 real projects.
- Raw JSON, methodology, case studies, README, SECURITY, and announcement draft are coherent and do not overclaim.
- Tarball dry-run is clean and professional.

## Failure Conditions

Treat the release as not done if any criterion is uncertain, proxied, or unquoted. Compilation, a passing added test, or a clean-looking diff is not enough. The final verify command and the benchmark/report artifacts are the receipts.
